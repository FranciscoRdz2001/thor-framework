# Examples

Small, complete apps and interaction patterns, each with a live example and the code to adapt it to your app.

## Applications

The seven tasks from [7GUIs](https://eugenkiss.github.io/7guis/), from simplest to most complex, plus a content page.

:::cards
- [Counter](examples/counter.md) — a number that goes up with every press
- [Temperature converter](examples/temperature.md) — two fields that update each other
- [Flight booker](examples/flight-booker.md) — dates that are validated and a button that gets enabled
- [Timer](examples/timer.md) — a bar that advances on its own and an adjustable duration
- [CRUD list](examples/crud.md) — filter, create, update and delete in a list
- [Circles with undo](examples/circle-drawer.md) — a canvas with selection, a dialog and history
- [Spreadsheet](examples/cells.md) — cells with formulas that depend on each other
- [Content page](examples/content-page.md) — a landing page with a theme, images and metadata
:::

## Interaction patterns

Motion details with controls for their duration, curve or intensity. All of them respect the reduced-motion preference.

:::cards
- [Slide to confirm](examples/slide-to-confirm.md) — a handle you drag all the way to the end
- [Copy button](examples/copy-button.md) — an icon that turns into a checkmark
- [Tabs with indicator](examples/tab-indicator.md) — an indicator that slides between tabs
- [Toast stack](examples/toast-stack.md) — toasts that stack up and leave the way they came in
:::
