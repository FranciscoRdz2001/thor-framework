Tabs with indicator

A tab bar whose indicator slides from one tab to another.

  • FlutterTabBar(indicator:)
  • ThorAnimatedSlide inside a Watch
Three orders to deliver and one on the way.
300 ms
App code
class TabsViewModel extends ThorState {
  final current = state(0);
 
  int currentTab() => current.value;
  void go(int index) => current.value = index;
}
 
final tabs = TabsViewModel();
 
final indicator = filledBox; // a rounded box under the label
Watch(
  tabs.currentTab,
  count: 3,
  builder: (i) => Stack(children: [
    // One element that slides under the labels.
    AnimatedSlide(
      offset: Offset(i.toDouble(), 0),
      duration: Duration(milliseconds: 300),
      curve: Curves.easeInOut,
      child: indicator,
    ),
    Row(children: [
      for (var t = 0; t < 3; t++)
        Gesture(
          onTap: tabs.go.withArg(t),
          child: AnimatedDefaultTextStyle(
            style: t == i ? selected : idle,
            duration: Duration(milliseconds: 150),
            child: Text(labels[t]),
          ),
        ),
    ]),
  ]),
)

Tab indicator

The indicator is a single element that slides under the labels; the content below changes with a fade.
Indicator
Pill
Line
Curve
easeOut
easeInOut
easeOutBack
Duration
300 ms

The indicator is a single element as wide as one tab. AnimatedSlide moves it in multiples of its own width, so tab i sits at Offset(i, 0) regardless of the text. The color of each label changes with AnimatedDefaultTextStyle.

Note

If you don't need a custom indicator, TabBar includes its own.
