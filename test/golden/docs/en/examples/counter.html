Counter

A number and a button that increments it with every press.

  • FlutterStatefulWidget and setState
  • ThorThorState and Watch
0
Dart
class CounterViewModel extends ThorState {
  final count = state(0);
 
  String label() => '${count.value}';
  void increment() => count.value += 1;
}
 
final counter = CounterViewModel();
 
class CounterView extends StatelessWidget {
  const CounterView({super.key});
 
  @override
  Widget build(BuildContext context) => Row(
    spacing: 12,
    children: [
      Semantics(
        label: 'Count',
        liveRegion: true,
        child: Watch(counter.label),
      ),
      FilledButton(
        onPressed: counter.increment,
        child: Text('Count +1'),
      ),
    ],
  );
}

Counter

A label with the count and a button that increases it by the step.
Step
1

The ViewModel (ThorState) keeps the count in a state field, state(0). Watch shows what label returns and updates when the field changes; the button receives the increment method as onPressed, with no closures. liveRegion makes a screen reader announce the new number.
