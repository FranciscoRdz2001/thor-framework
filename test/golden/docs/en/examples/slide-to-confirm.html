Slide to confirm

An action that asks for a deliberate gesture: drag a handle all the way to the end to confirm it.

  • FlutteronHorizontalDragEnd
  • ThorGesture(onDragEnd:, drag: Drag(…))
Slide to confirmConfirmed
Threshold70 %
300 ms
App code
class SlideViewModel extends ThorState {
  final confirmed = state(false);
 
  void released(double dx, double dy) {
    if (dx >= 146) confirmed.value = true;
  }
}
 
final slide = SlideViewModel();
 
AnimatedPositioned(
  duration: Duration(milliseconds: 300),
  curve: Curves.easeOut,
  left: confirmed ? 208 : 4,
  child: Gesture(
    onDragEnd: slide.released,
    drag: Drag(axis: Axis.horizontal),
    child: handle,
  ),
)

Slide to confirm

Drag the handle to the end. The browser moves it with the pointer and the ViewModel receives only the final position: if it passes the threshold, it confirms; if not, the handle goes back to the start.
Curve
easeOut
easeInOut
easeOutBack
Threshold
70 %
Duration
300 ms

While the pointer is down, the browser moves the handle; the ViewModel (ThorState) only receives the distance on release, and Drag returns the handle to its place if it didn't reach the end. On confirm, the track and the handle change with AnimatedContainer and AnimatedPositioned.

Tip

Add a button with the same action for people who can't drag.
