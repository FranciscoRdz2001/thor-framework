IconButton

An icon button with an accessible name: change the icon size.
Enabled
Size
24 px

A 48 × 48 button with an icon. tooltip is its accessible name and the text that appears on hover.

ParameterWhat it does
iconthe Icon it shows
tooltipthe accessible name and the bubble
hrefturns it into a link; requires tooltip
color, iconSizethe icon's color and size
isSelected, selectedIcona toggle button, with its selected icon
visualDensity, padding, constraintsthe size of the box
Important

An icon is decorative: an IconButton without tooltip is announced only as "button". The analyzer flags it with icon_button_without_name.

ButtonStyle and styleFrom

A button's shape, radius and padding with styleFrom.
Shape
Rounded
Stadium
Radius
8 px
Padding
28 px

Every button takes style. FilledButton.styleFrom, OutlinedButton.styleFrom and TextButton.styleFrom build it from simple values, as in Flutter; ButtonStyle(animationDuration:) animates the change between states.

styleFrom parameterWhat it changes
backgroundColor, foregroundColorbackground and text
overlayColorthe background on hover
padding, minimumSizethe size
shape, sidethe shape (RoundedRectangleBorder, StadiumBorder, CircleBorder) and the border
textStylethe typography
disabledBackgroundColorthe background without onPressed

Per-state style

ButtonStyle fields are WidgetStateProperty, as in Flutter: a value can depend on hovered, focused, pressed, selected or disabled. The server compiles each state; the browser computes nothing.

FilledButton(
  onPressed: save,
  style: ButtonStyle(
    backgroundColor: WidgetStateProperty.resolveWith((states) {
      if (states.contains(WidgetState.disabled)) return Colors.grey;
      if (states.contains(WidgetState.hovered)) return Colors.teal;
      return null; // the variant's color
    }),
  ),
  child: const Text('Save'),
)
Difference from Flutter

Only backgroundColor, foregroundColor, side and overlayColor change per state. A value for a combination of states (hovered and focused at once) is resolved with each state separately.

disabled covers a button without onPressed (disabled) and one with aria-disabled="true", which stays focusable: both look disabled and neither gets the hover.
