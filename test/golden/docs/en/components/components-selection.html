Selection

Controls to turn something on or off, or to choose between options. They notify the ViewModel (ThorState) with onChanged, or with onSelected on chips; without that callback they are disabled.

RadioGroup and Radio

The group holds the selected value; each Radio only states its value.
Selected
Card
Cash
Bank
Enabled

RadioGroup holds the selected value and reports changes; each Radio declares only its value. It also groups RadioListTile.

RadioGroup parameterWhat it does
groupValuethe selected value: the Radio with that value is checked
onChangedthe method that receives the value; null disables the group
namethe name it's submitted under in a Form

It works the same without JavaScript: the browser keeps one radio checked, the arrow keys move through them and a Form submits the value. An enum is submitted as its name.

Note

Radio(groupValue:, onChanged:) and RadioListTile(groupValue:, onChanged:) are @Deprecated, as in Flutter: use RadioGroup.

SegmentedButton

Several native segments to pick a value: without JavaScript you can pick and move through them with the arrow keys.
Enabled

A row of segments to choose one value, or several with multiSelectionEnabled: true. onSelectionChanged receives the new set: a method with a Set<T> parameter.

ParameterWhat it does
segmentsthe ButtonSegment(value:, label:, icon:, tooltip:, enabled:)
selectedthe set selected when the page is rendered
onSelectionChangedthe method that receives the Set<T>; null disables it
multiSelectionEnabledallows selecting several segments
showSelectedIcon, selectedIconthe mark on the selected segment
style, direction, expandedInsetsthe look, the orientation and full width

Pill toggle

With StadiumBorder in style.shape, the group and the selected segment are fully rounded. groupPadding and groupColor make the rail; selectedStyle paints the selected segment.

import 'package:thor_ui/thor_ui.dart';

class SegmentedPillDemo extends StatelessWidget {
  const SegmentedPillDemo({super.key});

  @override
  Widget build(BuildContext context) => const SegmentedButton<String>(
    segments: [
      ButtonSegment(value: 'monthly', label: Text('Mensual')),
      ButtonSegment(value: 'yearly', label: Text('Anual')),
    ],
    selected: {'monthly'},
    showSelectedIcon: false,
    groupPadding: EdgeInsets.all(4),
    groupColor: Color(0xFFF3F4F6),
    style: ButtonStyle(
      shape: WidgetStatePropertyAll(StadiumBorder()),
      side: WidgetStatePropertyAll(BorderSide.none),
    ),
    selectedStyle: ButtonStyle(
      backgroundColor: WidgetStatePropertyAll(Color(0xFF4F46E5)),
      foregroundColor: WidgetStatePropertyAll(Color(0xFFFFFFFF)),
    ),
  );
}

Chips that are links

With href the chip is a link and works without JavaScript.
Selected
Checkmark
× as link

Chip, InputChip, FilterChip, ChoiceChip and ActionChip accept href: the chip is a link and works without JavaScript, useful for filters that change the URL. On an InputChip or a Chip, deleteHref makes the X another link, to the page without that filter.

Difference from Flutter

href and deleteHref don't exist in Flutter. The X is a button next to the chip, not inside it.
