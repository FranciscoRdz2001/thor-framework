Define colors, typography and component themes once in ThemeData, and vary any value by width, state or dark mode with .when().

Theme colors

Widgets read the theme with ThemeColor or Theme.of(context), without repeating any color: when the theme changes, everything that reads it updates.

Difference from Flutter

ColorScheme.fromSeed does not exist. Write the roles that change (ColorScheme.light(primary: …)); the rest take the Material 3 values.

Color roles

Each colorScheme role has one value in the light theme and another in the dark one. These are the most used:

RoleUse
primarymain actions, links and focus
onPrimarytext and icons on primary
surfacethe page background
onSurfacethe page text
surfaceContainercards and panels
errorerrors and destructive actions

The API reference lists the rest of the ColorScheme roles.

Custom colors

Declare each brand color with ColorToken: it is a const Color that carries its light value and its dark value.

abstract final class AppColors {
  static const band = ColorToken('band',
      light: Color(0xFFF7F6F2), dark: Color(0xFF22252A));
  static const muted = ColorToken('muted',
      light: Color(0xFF697077), dark: Color(0xFFA6ACB3));
  static const values = [band, muted];
}

final light = ThemeData(tokens: AppColors.values);
final dark = ThemeData(
    colorScheme: const ColorScheme.dark(), tokens: AppColors.values);

Container(color: AppColors.band)       // follows the theme

Two tokens with the same name are error THOR-R021. For scales from 50 to 950 there is ColorScale, and Colors.blue.shade700 works as in Flutter.

// The dark switch is a state here because the docs page has one theme; in an
// app it is the system's mode or a ThemeToggle. What matters: the boxes read
// Theme.of(context) and follow, with nothing rebuilt by hand.
class ThemeSwitchViewModel extends ThorState {
  final dark = state(false);

  bool isDark() => dark.value;
  void setDark(bool on) => dark.value = on;
}

final themeSwitch = ThemeSwitchViewModel();

class ThemeSwitchExample extends StatelessWidget {
  const ThemeSwitchExample({super.key});

  @override
  Widget build(BuildContext context) => Column(
    mainAxisSize: MainAxisSize.min,
    crossAxisAlignment: CrossAxisAlignment.start,
    spacing: 12,
    children: [
      Row(
        mainAxisSize: MainAxisSize.min,
        spacing: 8,
        children: [
          Switch(
            value: false,
            onChanged: themeSwitch.setDark,
            semanticLabel: 'Dark mode',
          ),
          const Text('Dark mode'),
        ],
      ),
      Watch(
        themeSwitch.isDark,
        builder: (dark) => Theme(
          data: ThemeData(
            colorScheme: dark
                ? const ColorScheme.dark()
                : const ColorScheme.light(),
          ),
          child: const _Swatches(),
        ),
      ),
    ],
  );
}

The user's choice is saved in the browser and applied before the page is shown: there is no flash on reload. It requires 2024 browsers (Chrome 123, Safari 17.5, Firefox 120).

Important

A literal Color is the same in both themes. For a color to follow dark mode, read it from the theme (ThemeColor.primary) or declare a ColorToken.

Reading the theme in code

Theme.of(context).colorScheme returns colors that follow dark mode, also with withValues(alpha:).

final scheme = Theme.of(context).colorScheme;
Container(
  color: scheme.primary.withValues(alpha: 0.15),
  child: Text('x', style: TextStyle(color: scheme.onSurface)),
)
ExpressionResult
scheme.primary in a color, border or textfollows dark mode
scheme.primary.withValues(alpha: .15)follows dark mode
.value, .red, .opacity, Color.alphaBlend (also on Color.css and .when() colors; hasChannels tells)error THOR-R023
scheme.primary.fallback!.valuethe color of a single mode
scheme.brightnessthe theme's
Difference from Flutter

The server renders the page once and does not know the user's mode, so Theme.of does not return a fixed color. To choose between two colors use .when(dark: …).

A text style

copyWith changes the size and weight of a TextTheme role; the rest of the style follows the theme.
Size
28 px
Weight
w600

To make a role grow on wide screens, give the whole TextTheme a variant:

textTheme: textTheme.when(
  medium: textTheme.copyWith(displayLarge: const TextStyle(fontSize: 60)),
),

For a size that grows with the window, TextStyle also accepts a Length (Units):

const TextStyle(
  fontSize: 40,                                   // the number Dart reads
  fontSizeLength: Length.clamp(Length.px(40), Length.vw(5), Length.px(72)),
  letterSpacingLength: Length.em(-0.02),
)

Fonts

Each FontFace is a font file of the app: the equivalent of the fonts: section in Flutter's pubspec.yaml.

fonts: [
  // A variable font: every weight in one file.
  FontFace('Inter', url: '/fonts/inter.woff2',
      weight: FontWeight.w100, maxWeight: FontWeight.w900, preload: true),
  // One file per weight or style.
  FontFace('Mono', url: '/fonts/mono-400.woff2'),
  FontFace('Mono', url: '/fonts/mono-500.woff2', weight: FontWeight.w500),
],
OptionEffect
display:what shows while it loads; FontDisplay.swap (the default) never hides the text
preload: truedownloads the file earlier; use it only for the first screen's font
thor fonts subsettrims the font to the characters the app uses
thor fonts metricsmeasures a FontFallback with the same proportions, so the text doesn't jump

The files go in the app's web/. If they come from a package, the package declares them and thor dev copies them.

Flutter's themes exist for cards, chips, buttons, fields, dividers, dialogs, bars, lists, snackbars, menus, tabs and selection controls: cardTheme, chipTheme, filledButtonTheme, iconButtonTheme, inputDecorationTheme, dialogTheme, appBarTheme, listTileTheme, snackBarTheme, tabBarTheme, checkboxTheme, switchTheme and the rest. The widget's parameter wins, then the theme, and finally the default value.

Each XThemeData carries the Flutter fields the browser can apply; each class's documentation lists the missing ones. Theme.provide(data:) changes the theme of a subtree, and a ThemeExtension holds your brand's own values.

Variants with .when()

Whatever changes by width, state or theme is a value with .when(). The variant only carries what changes; the rest is inherited from the base value.

Container(padding: const EdgeInsets.all(24).when(medium: EdgeInsets.all(32)))

BoxDecoration(color: ThemeColor.surface.when(hover: ThemeColor.surfaceContainer))

Text('Pricing', style: ThemeText.titleMedium.when(medium: ThemeText.titleLarge))

Grid(layout: GridLayout(columns: 1, gap: 16).when(expanded: GridLayout(columns: 3, gap: 32)))

import 'package:thor_ui/thor_ui.dart';

class ResponsiveVariants extends StatelessWidget {
  const ResponsiveVariants({super.key});

  @override
  Widget build(BuildContext context) => Container(
    padding: const EdgeInsets.all(12).when(medium: const EdgeInsets.all(24)),
    decoration: BoxDecoration(
      color: ThemeColor.surfaceContainer.when(
        hover: ThemeColor.secondaryContainer,
        pressed: ThemeColor.secondaryContainer,
      ),
      borderRadius: BorderRadius.circular(12),
    ),
    child: Flex(
      direction: Axis.vertical,
      // A column on a phone, a row from md on.
      layout: const FlexLayout(
        spacing: 8,
      ).when(medium: const FlexLayout(direction: Axis.horizontal, spacing: 24)),
      children: [
        Text(
          'Resize the window',
          style: const TextStyle(fontSize: 14).when(
            medium: const TextStyle(fontSize: 18, fontWeight: FontWeight.w700),
          ),
        ),
        const Text('or hover (tap) the box'),
      ],
    ),
  );
}

VariantApplies
medium, expanded, large, extraLargefrom 600, 840, 1200 and 1600 px of window width (the Material 3 size classes)
darkwith the dark theme
hover, focused, pressedon hover, with keyboard focus, while pressed
openwhile the nearest <details> is open (an ExpansionTile: its header and its content); a nested one decides for what it holds
groupHoveron hover over the nearest HoverGroup
groupHovers: {'card': …}the same, for the nearest HoverGroup(name: 'card')
container: {400: …}when the nearest LayoutScope measures at least 400 px

These accept .when(): EdgeInsets, BorderRadius, BoxConstraints, BoxDecoration, TextStyle, Color, TextTheme, GridLayout, FlexLayout, CarouselLayout and StyleProps. A bare number (double, int) does not take variants: it goes in a StyleProps inside Styled (Advanced styles). Widths are changed with ThemeData(breakpoints: Breakpoints(medium: 640)), and a variant can have its own: color.when(hover: hover.when(medium: other)).

Arithmetic (padding * 2, padding + extra) and copyWith on one of these values apply to the base and to every variant, so the variants are kept.

Note

hover and groupHover only apply with a pointer that can hover (mouse, trackpad). On a phone, repeat the effect in pressed:.

Widgets take it in their Length variants: EdgeInsetsGeometry.allLength (also symmetricLength and onlyLength), BorderRadius.circularLength, SizedBox(widthLength:) and Positioned(leftLength:).

Container(
  padding: EdgeInsetsGeometry.allLength(card.padding.px),
  decoration: BoxDecoration(
    borderRadius: BorderRadius.circularLength(card.radius.px),
  ),
)

SizedBox(widthLength: card.width.px, child: content)
Positioned(leftLength: drag.x.px, top: 0, child: handle)
Important

An EdgeInsetsGeometry is not an EdgeInsets: it has no left or horizontal. Parameters that require EdgeInsets (TextField.contentPadding, Dialog.insetPadding) don't accept a Length.

EdgeInsetsDirectional(start:, end:), BorderRadiusDirectional and AlignmentDirectional follow the text direction, as in Flutter.
