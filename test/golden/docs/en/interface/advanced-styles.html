What to use, in order

Start at the top and go down a level only when the previous one isn't enough.

1
Widget props
first

Almost everything: Container(padding:, decoration:), Text(style:), Row(spacing:). It's what you would write in Flutter.

2
Wrappers

To decorate without adding elements: Padding, Opacity, Transform, BackdropFilter (blurs what is behind), ClipRRect, Link. They merge into their child's element.

3
Variants with .when()

What changes with width, state, theme or container size: EdgeInsets.all(16).when(medium: EdgeInsets.all(32)). See Theme and styles.

4
StyleProps in Styled

What no widget expresses: fixed positioning, inner scrolling, units like 100.dvh, and numbers that change with .when(). See StyleProps in Styled.

5
Your own stylesheets

Your components' classes and the states no widget expresses. See Your own stylesheets.

6
Styled(descendants:)
last resort

HTML that no widget builds, such as markdown or content from a CMS. See HTML without widgets.

Every level is typed: the analyzer catches a typo, the editor autocompletes, and values that come from your data are escaped before they reach the page.

StyleProps in Styled

Styled(style:) applies a StyleProps to its child's element, without adding another one. In the list, each letter sticks to the top (BoxPosition.sticky) until the next one pushes it away.

Styled(
  style: StyleProps(
    position: BoxPosition.sticky(top: 0.px),
    zIndex: 20,
    maxHeight: 100.dvh - 72.px,
    overflowY: Overflow.auto,
  ),
  child: TableOfContents(),
)

// The box scrolls: `focusable` lets the keyboard scroll it too, and the
// region role names it for a screen reader.
class StickyList extends StatelessWidget {

  @override
  Widget build(BuildContext context) => Semantics(
    role: SemanticsRole.region,
    focusable: true,
    label: 'Contacts',
    child: Styled(
      style: StyleProps(maxHeight: 220.px, overflowY: Overflow.auto),
      child: Container(
        width: 300,
        decoration: BoxDecoration(
          color: _card,
          border: Border.all(color: _line),
          borderRadius: BorderRadius.circular(12),
        ),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            for (final (letter, names) in const [
              ('A', ['Ada', 'Alan', 'Anita']),
              ('B', ['Barbara', 'Bjarne']),
              ('D', ['Dennis', 'Donald', 'Dorothy']),
              ('G', ['Grace', 'Guido']),
            ]) ...[
              Styled(
                style: const StyleProps(
                  position: BoxPosition.sticky(top: Length.zero),
                  zIndex: 1,
                ),
                child: Container(
                  color: _tint,
                  padding: const EdgeInsets.symmetric(

BoxPosition takes its distances as Length: BoxPosition.fixed(bottom: 16.px, right: 16.px). Inside a Stack, use Positioned as in Flutter.

Styled doesn't replace widgets. What a widget already expresses (padding, decoration, color, a fixed number) goes in that widget; the widget_props_in_styled lint flags it.

// WRONG (widget_props_in_styled): padding belongs to a widget
Styled(style: StyleProps(padding: EdgeInsets.all(12)), child: child)

// RIGHT
Padding(padding: EdgeInsets.all(12), child: child)

// Hover each tile (or press it on a touch screen, where hover doesn't
// exist): the values change with .when(hover:, pressed:) and Styled's
// duration turns the change into a transition.
class HoverEffects extends StatelessWidget {
  const HoverEffects({super.key});

  @override
  Widget build(BuildContext context) => Wrap(
    spacing: 12,
    runSpacing: 12,
    children: [
      _Tile(
        'turns',
        const StyleProps(turns: 0).when(
          hover: const StyleProps(turns: -0.02),
          pressed: const StyleProps(turns: -0.02),
        ),
      ),
      _Tile(
        'offset + scale',
        const StyleProps(offset: Offset.zero, scale: 1).when(
          hover: const StyleProps(offset: Offset(0, -6), scale: 1.04),
          pressed: const StyleProps(offset: Offset(0, -6), scale: 1.04),
        ),
      ),
      _Tile(
        'blur',
        const StyleProps(blur: 3).when(
          hover: const StyleProps(blur: 0),
          pressed: const StyleProps(blur: 0),
        ),
      ),
    ],
  );
}

Units

Flutter props are measured in logical pixels (double): EdgeInsets.all(16) is 16 pixels. For things measured differently, such as the window's height or a fraction of the parent, there is Length.

16.px            // 16 logical pixels
50.percent       // half of the parent
1.5.em           // 1.5 × the element's font size
1.rem            // 1 × the page's font size
60.ch            // about 60 characters: a good reading width
100.vw           // the window's width
100.dvh          // the window's height now (follows a phone's bars)
96.px
50.percent
8.rem
20.ch
12.vw
Length.clamp(4.rem, 15.vw, 100.percent)

          ('96.px', 96.px),
          ('50.percent', 50.percent),

                style: StyleProps(minWidth: length, maxWidth: length),

    ),
  );
}

Operations combine units, and limits are written with min, max and clamp:

100.dvh - 48.px                          // the window minus a bar
(100.vw - 2.rem) / 3                     // a third of the window, minus margins
Length.min([100.percent, 720.px])        // the parent, at most 720 px
Length.clamp(1.rem, 2.vw + 1.rem, 3.rem) // grows with the window, with limits
card.gap.px * 2                          // follows a state field

Length.px(16), Length.min, Length.max and Length.clamp are const; 16.px is the short form.

An element with containerType: ContainerType.size is a measuring box: inside it, 100.cqw and 100.cqh are its width and height (also cqi, cqb, cqmin, cqmax). That box doesn't grow with its content: give it a height of its own (Expanded, heightLength). Ratio.of(a, b) is a divided by b (how many times b fits in a), a plain number the browser computes; with StyleProps(scaleRatio:) it scales a box to fit its container, with no JS and no breakpoints:

Expanded(
  child: Styled(
    style: const StyleProps(containerType: ContainerType.size),
    child: SizedBox.expand( // the stage
      child: Styled(
        style: StyleProps(
          transformOrigin: Alignment.topLeft,
          scaleRatio: Ratio.min([
            Ratio.value(1), // never above 100%
            Ratio.of(100.cqh, 844.px),
            Ratio.of(100.cqw, 390.px),
          ]),
        ),
        child: device, // 390 x 844
      ),
    ),
  ),
)

Styled melts into its child's element, so the stage is a widget with its own element (here SizedBox.expand): cq units measure an ancestor, never the element itself.

Difference from Flutter

Flutter computes layout in Dart and doesn't need units. On the web the browser computes it, and sometimes the value is "the window's height" or "half of the parent". Length shows up only where Flutter has no equivalent.

Your own stylesheets

For your components' classes, write rules with css() and give them values with .props(), the same StyleProps as above. A component's stylesheet lives with it, in css.components:

import 'package:thor_ui/html.dart' show css;
import 'package:thor_ui/thor_ui.dart';

class ProductCard extends StatelessWidget {
  const ProductCard({super.key});

  static final styles = css.components([
    css('.product-card', [
      css('&').props(const StyleProps(padding: EdgeInsets.all(12))),
      css('&:hover').props(const StyleProps(offset: Offset(0, -2))),
    ]),
  ]);

  @override
  Widget build(BuildContext context) =>
      Styled(classes: const ['product-card'], child: const Text('Cold brew'));
}

Styled(classes:) adds the class to the child's element. A stylesheet for the whole app is passed once in ThorApp.router(styles:), and one used only by the routes of a group goes in Group(styles:), so other pages don't download it:

lib/styles.dart
import 'package:thor_ui/html.dart' show css;
import 'package:thor_ui/thor_ui.dart';

final List<StyleRule> appStyles = [
  css('.card', [
    css('&').props(StyleProps(
      padding: const EdgeInsets.all(12),
      decoration: BoxDecoration(borderRadius: BorderRadius.circular(16)),
    )),
    css('&:hover').props(const StyleProps(offset: Offset(0, -2))),
  ]),
  WindowSizeClass.medium.media([
    css('.card').props(const StyleProps(padding: EdgeInsets.all(16))),
  ]),
];

A rule varies with its selector and with WindowSizeClass.media; .when() is for widgets.

Important

Rules in your stylesheets always win over widget styles. Use them for your own classes, not to change every element of a type, and don't put a transition on an element that an Animated* already animates: it replaces it.

A component's stylesheet (css.components) sits below the elements' own props: .row:hover .name does not beat the fontWeight of the Text inside. For a descendant that changes with an ancestor's state (:hover, :has([aria-current]), [open]), use css.states, which comes after them:

import 'package:thor_ui/html.dart' show css;
import 'package:thor_ui/thor_ui.dart';

final styles = css.states([
  css('.tree-row:has(a[aria-current]) .tree-name')
      .props(const StyleProps(textStyle: TextStyle(fontWeight: FontWeight.w600))),
]);

Stylesheets by level

Each stylesheet belongs to a level (theme, components, app, module or page); Build and deploy explains how to share them across pages so the browser caches them.

HTML without widgets

Rendered markdown or content from a CMS doesn't come from widgets, so it has no props. Styled(descendants:) styles it with types, scoped to the element that wraps it.

Styled(
  descendants: {
    '> * + *': const StyleProps(margin: EdgeInsets.only(top: 14)),
    'h2': const StyleProps(
      textStyle: TextStyle(fontSize: 22, fontWeight: FontWeight.w700),
      margin: EdgeInsets.only(top: 36),
    ),
    'a': const StyleProps(
      textStyle: TextStyle(decoration: TextDecoration.underline),
    ),
    'img': StyleProps(maxWidth: 100.percent),
  },
  child: DefaultTextStyle(
    style: const TextStyle(fontSize: 16, height: 1.7),
    child: Container(child: html.RawText(markup)),
  ),
)

// HTML no widget builds (rendered markdown, a CMS body): styled by tag,
// scoped to this element.
class ReleaseNotes extends StatelessWidget {
  const ReleaseNotes({super.key});

  @override
  Widget build(BuildContext context) => Styled(
    descendants: {
      'h3': const StyleProps(
        textStyle: TextStyle(fontSize: 17, fontWeight: FontWeight.w700),
        // Only these two sides: the others keep the browser's.

Each key is a selector inside the element (h2, a:hover, pre code) and each value is a StyleProps without variants. The container's text still goes through its widget (DefaultTextStyle).

No raw: for the common cases: EdgeInsetsGeometry.sides sets only the sides it is given (the browser's others stay), and a Length in em follows the text around it.

Styled(
  descendants: {
    '> :first-child': StyleProps(
      margin: EdgeInsetsGeometry.sides(top: Length.zero),
    ),
    ':not(pre) > code': StyleProps(
      textStyle: TextStyle(fontSizeLength: 0.9.em, heightLength: 1.25.em),
    ),
    'h2': StyleProps(textStyle: TextStyle(fontWeight: FontWeight(650))),
    'img.right': StyleProps(float: BoxFloat.right),
  },
  child: Container(child: html.RawText(markup)),
)

Gradient patterns

A gradient with tile: repeats as a tile: a dotted or striped background with no images.

BoxDecoration(
  color: const Color(0xFFECEEF3),
  gradient: RadialGradient(
    colors: [const Color(0xFF4F46E5).withValues(alpha: 0.16), const Color(0x00000000)],
    stops: const [0.125, 0.125],      // a 1px dot (0.125 of the 8px radius)
    tile: const Size.square(16),      // every 16px
  ),
)
import 'package:thor_ui/thor_ui.dart';

const _line = ThemeColor.outlineVariant;

// A gradient repeated in tiles: dots and stripes, no image.
class TiledPatterns extends StatelessWidget {
  const TiledPatterns({super.key});

  @override
  Widget build(BuildContext context) => const Row(
    spacing: 12,
    children: [
      _Pattern(
        RadialGradient(
          colors: [Color(0x664F46E5), Color(0x00000000)],
          stops: [0.2, 0.2],
          tile: Size.square(14),
        ),
      ),
      _Pattern(
        LinearGradient(
          begin: Alignment.topLeft,
          end: Alignment.bottomRight,
          colors: [
            Color(0x334F46E5),
            Color(0x334F46E5),
            Color(0x00000000),
            Color(0x00000000),
          ],
          stops: [0, 0.5, 0.5, 1],
          tile: Size.square(12),
        ),
      ),
    ],
  );
}

class _Pattern extends StatelessWidget {
  const _Pattern(this.gradient);

  final Gradient gradient;

  @override
  Widget build(BuildContext context) => Container(
    width: 140,
    height: 90,
    decoration: BoxDecoration(
      gradient: gradient,
      border: Border.all(color: _line),
      borderRadius: BorderRadius.circular(12),
    ),
  );
}
