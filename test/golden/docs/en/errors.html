Error codes

Thor's most common errors and warnings carry a stable code (THOR-S001) and a page here with the cause and how to fix it (/errores/THOR-S001). Those from the browser and the development inspector carry only the code, and the thor dev overlay links them all the same.

On this page
StateRenderLayout (development inspector)Pages and serverBuild and code generation

A code is never reused and never changes meaning: if an error stops existing, its page is deleted and the code stays unused.

Letters: S state · R render · L layout (inspector) · P pages and server · B build and code generation.
