What is Thor

Thor renders Flutter widgets as semantic HTML and CSS on the server. This page helps you decide whether it fits your app.

On this page
One widget, one pageWhat runs whereThor or Flutter webNext steps
  • Flutterwidgets painted on its own canvas
  • Thorthe same widgets, as HTML and CSS

One widget, one page

You write a StatelessWidget as in Flutter. Thor runs its build on the server and sends the browser an HTML element with its CSS class.

Hello, Thor

Flutter widgets in, semantic HTML out.
import 'package:thor_ui/thor_ui.dart';

class WelcomeCard extends StatelessWidget {
  const WelcomeCard({super.key});

  @override
  Widget build(BuildContext context) => Container(
    width: 280,
    padding: const EdgeInsets.all(20),
    decoration: BoxDecoration(
      color: ThemeColor.surfaceContainer,
      borderRadius: BorderRadius.circular(16),
    ),
    child: Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      spacing: 8,
      children: [
        const Semantics(
          headingLevel: 2,
          child: Text('Hello, Thor', style: ThemeText.titleLarge),
        ),
        const Text('Flutter widgets in, semantic HTML out.'),
        FilledButton(onPressed: () {}, child: const Text('Get started')),
      ],
    ),
  );
}

What runs where

Widget code runs on the server; the browser does the layout and updates only what changes.

Part of the appRuns onWhat it does
each widget's buildserverrenders the HTML and CSS, once per request
each page's loadserverloads the data before rendering
layout, scrolling and animationsbrowserapplied with CSS, without JavaScript
ViewModel (ThorState)browserupdates what changes without reloading the page

JavaScript only reaches pages that use a ViewModel. The details are in What runs where.

Thor or Flutter web

Choose Thor if…Choose Flutter web if…
the site must be indexed: a store, a blog, documentationthe app paints every pixel: an editor, a game
you need selectable text, links, zoom and native formsyou need the same rendering on mobile, desktop and web
the first screen must show content without waiting for JavaScriptthe app already exists in Flutter and rewriting it isn't worth it

To combine both, Embedded Flutter places a Flutter app inside a region of the page.
