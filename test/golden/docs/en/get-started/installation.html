Installation

Install the thor command, create an app and open it in the browser. You need Dart and an editor.

Note

Thor is at version 0.1 and is not yet published on pub.dev. The thor command is installed from a local copy of the repository, and every new project uses that copy.

Install and create an app

Clone the repository, activate the command and create the app. thor dev serves it at http://localhost:4300, or on the next free port.

Set up the editor

WhatHow
Dartyour editor's Dart extension (VS Code, Cursor, IntelliJ, Zed)
Thor rulesalready on: thor create adds them to analysis_options.yaml and the editor flags what doesn't work in the browser, with its THOR-* code
From the browser to the codewith thor dev, Alt+click (Option on Mac) on an element opens the file that built it; THOR_EDITOR=cursor picks the editor

Environment variables

lib/env.dart declares the variables with their types; the values go in .env, at the app root, which thor create adds to .gitignore.

.env
API_URL=https://api.example.com
SESSION_SECRET=a-long-key-of-at-least-32-characters

thor dev and thor preview read .env. If a variable is missing, the server doesn't start and lists every missing one (THOR-P011). Types and secret protection are in Session and security.

Continuous integration

thor create writes .github/workflows/ci.yml, which installs thor and runs formatting, dart analyze --fatal-infos and thor test. CI can only install Thor from a repository: create the project with --git <url> or point the pubspec.yaml dependency to a repository.

Tip

thor analyze and thor format --check run the same checks as CI on your machine.

Common commands

CommandWhat it does
thor devruns the app and updates it on every change
thor testruns the tests
thor analyzeanalyzes the project with Thor's rules
thor buildbuilds the production version
thor previewserves the built version at http://localhost:4400
thor doctor --fixchecks the SDK and the project, and applies the safe fixes

Every command and its options are in The thor command.
