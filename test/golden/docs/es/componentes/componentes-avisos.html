AlertDialog

Un diálogo nativo con título, contenido y acciones: ábrelo con el botón.
Cierra al tocar fuera
Contenido
Dos acciones

Un diálogo con título, contenido y acciones. DialogTrigger(dialog:) lo coloca junto al botón que lo abre y DialogClose cierra el diálogo desde una acción. Se cierra con Esc y, con barrierDismissible: true, con un toque fuera.

Diferencia con Flutter

No existe showDialog(context): el diálogo está en la página desde que se renderiza, cerrado, junto al DialogTrigger que lo abre.

Delete a contact?
Dart
class ContactsViewModel extends ThorState {
  final count = state(3);
  final confirm = DialogController();
 
  void askDelete() => confirm.open();
  void delete() {
    if (count.value > 0) count.value--;
    confirm.close();
  }
}

SnackBar

Un mensaje breve que se oculta solo: con o sin acción, más corto o más largo.
Flotante
Acción
Duración
2 s
4 s
6 s

Un mensaje breve en la parte inferior, que los lectores de pantalla anuncian. SnackBarBehavior.fixed, el valor por omisión, ocupa todo el ancho; SnackBarBehavior.floating es una tarjeta centrada. Se oculta después de duration, y la cuenta se pausa mientras tiene el puntero o el foco.

Para mostrar un mensaje desde un método, llama a toast(): no necesita BuildContext, se oculta solo y forma una cola.

void save() {
  // …
  toast('Changes saved', duration: const Duration(seconds: 3));
}
Diferencia con Flutter

No existe ScaffoldMessenger. toast(), hideToast() y clearToasts() reemplazan a showSnackBar, hideCurrentSnackBar y clearSnackBars; para un mensaje en la página siguiente, usa Redirect(url).flash('…').
