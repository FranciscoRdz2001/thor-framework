Selección

RadioGroup y Radio

El grupo guarda el valor elegido; cada Radio solo dice su value.
Elegido
Tarjeta
Efectivo
Banco
Habilitado

RadioGroup guarda el valor elegido y avisa del cambio; cada Radio declara solo su value. También agrupa RadioListTile.

Parámetro de RadioGroupQué hace
groupValueel valor elegido: se marca el Radio con ese value
onChangedel método que recibe el valor; null deshabilita el grupo
nameel nombre con el que se envía en un Form

Sin JavaScript funciona igual: el navegador mantiene un radio marcado, las flechas los recorren y un Form envía el valor. Un enum se envía como su name.

Nota

Radio(groupValue:, onChanged:) y RadioListTile(groupValue:, onChanged:) están @Deprecated, como en Flutter: usa RadioGroup.

SegmentedButton

Varios segmentos nativos para elegir un valor: sin JavaScript se elige y se recorre con las flechas.
Habilitado

Una fila de segmentos para elegir un valor, o varios con multiSelectionEnabled: true. onSelectionChanged recibe el conjunto nuevo: un método con un parámetro Set<T>.

ParámetroQué hace
segmentslos ButtonSegment(value:, label:, icon:, tooltip:, enabled:)
selectedel conjunto elegido al renderizar la página
onSelectionChangedel método que recibe el Set<T>; null lo deshabilita
multiSelectionEnabledpermite elegir varios segmentos
showSelectedIcon, selectedIconla marca del segmento elegido
style, direction, expandedInsetsel aspecto, la orientación y el ancho completo

Selector en píldora

Con StadiumBorder en style.shape, el grupo y el segmento elegido quedan redondos. groupPadding y groupColor forman el riel; selectedStyle pinta el segmento elegido.

import 'package:thor_ui/thor_ui.dart';

class SegmentedPillDemo extends StatelessWidget {
  const SegmentedPillDemo({super.key});

  @override
  Widget build(BuildContext context) => const SegmentedButton<String>(
    segments: [
      ButtonSegment(value: 'monthly', label: Text('Mensual')),
      ButtonSegment(value: 'yearly', label: Text('Anual')),
    ],
    selected: {'monthly'},
    showSelectedIcon: false,
    groupPadding: EdgeInsets.all(4),
    groupColor: Color(0xFFF3F4F6),
    style: ButtonStyle(
      shape: WidgetStatePropertyAll(StadiumBorder()),
      side: WidgetStatePropertyAll(BorderSide.none),
    ),
    selectedStyle: ButtonStyle(
      backgroundColor: WidgetStatePropertyAll(Color(0xFF4F46E5)),
      foregroundColor: WidgetStatePropertyAll(Color(0xFFFFFFFF)),
    ),
  );
}

InputChip

Una etiqueta de lo ya elegido, con su equis para quitarla.
Con equis
Habilitado
Etiquetas
3

Un valor que el usuario ya eligió o escribió, con una equis para quitarlo. onDeleted recibe un método del ViewModel y deleteButtonTooltipMessage cambia el nombre accesible de la equis.

Con onPressed se pulsa y con onSelected se alterna, como en Flutter; sin ninguno de los dos es una etiqueta como Chip.

Chips que son enlaces

Con href el chip es un enlace y funciona sin JavaScript.
Elegido
Marca
Equis enlace

Chip, InputChip, FilterChip, ChoiceChip y ActionChip aceptan href: el chip es un enlace y funciona sin JavaScript, útil para filtros que cambian la URL. En un InputChip o un Chip, deleteHref hace de la equis otro enlace, a la página sin ese filtro.

Diferencia con Flutter

href y deleteHref no existen en Flutter. La equis es un botón junto al chip, no dentro de él.
