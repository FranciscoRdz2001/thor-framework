AppBar

La barra de arriba: título centrado o no, botón de menú, acciones y elevación.
Título centrado
Botón de menú
Acción de búsqueda
Elevación
0

La barra superior, con leading, title y actions. Dentro de Scaffold(appBar:) queda fija mientras el contenido se desplaza.

ParámetroQué hace
leading, title, actionsel inicio, el título y los botones del final
bottomun widget debajo de la barra, como un TabBar
centerTitle, titleSpacing, toolbarHeightla posición del título y el alto de la barra
backgroundColor, foregroundColor, shapeel fondo, el color del texto y los íconos, y la forma
elevation, scrolledUnderElevationla sombra, y la sombra cuando el contenido pasa por debajo
flexibleSpaceun widget detrás de toda la barra, como una imagen o un degradado
AppBar(
  title: const Text('Sales'),
  elevation: 0,
  scrolledUnderElevation: 3,
  shape: const RoundedRectangleBorder(
    borderRadius: BorderRadius.vertical(bottom: Radius.circular(16)),
  ),
)

Scaffold

La estructura de una pantalla. Incluye un enlace «Saltar al contenido», visible solo con el foco del teclado; skipLink: false lo quita.

Scaffold(
  appBar: AppBar(title: const Text('Sales')),
  body: ListView(children: rows),
  floatingActionButton: FloatingActionButton(onPressed: add, child: const Icon(Icons.add)),
  floatingActionButtonLocation: FloatingActionButtonLocation.centerDocked,
  bottomNavigationBar: NavigationBar(destinations: tabs),
)
ParámetroQué hace
appBar, body, drawer, endDrawerlas regiones de la pantalla
bottomNavigationBar, bottomSheet, persistentFooterButtonslo que queda fijo abajo
floatingActionButton, floatingActionButtonLocationel botón flotante y su posición
extendBody, extendBodyBehindAppBarel contenido continúa por debajo de las barras
backgroundColor, drawerScrimColorel fondo y el velo detrás del cajón
Diferencia con Flutter

resizeToAvoidBottomInset no tiene efecto: el navegador decide cómo responde la página al teclado. bottomSheet está siempre visible; para una hoja que se abre, usa ModalBottomSheet.

Una región con scroll donde los slivers van uno tras otro: SliverAppBar, SliverList, SliverGrid, SliverToBoxAdapter, SliverPadding y SliverFillRemaining. SliverAppBar(pinned: true, expandedHeight:) se reduce hasta la barra mientras el contenido se desplaza, sin JavaScript.

CustomScrollView(
  slivers: [
    const SliverAppBar(pinned: true, expandedHeight: 160, title: Text('Sales')),
    SliverPadding(
      padding: const EdgeInsets.all(16),
      sliver: SliverGrid.extent(maxCrossAxisExtent: 240, children: cards),
    ),
    SliverList.builder(
      itemCount: rows.length,
      itemBuilder: (context, i) => ListTile(title: Text(rows[i])),
    ),
  ],
)
Diferencia con Flutter

Solo hay scroll vertical y sin reverse. floating y snap no tienen efecto, y no existen SliverPersistentHeader ni los delegates propios de SliverGrid.

La barra de destinos lateral, para pantallas anchas. Va dentro de un Row y ocupa todo su alto.

ParámetroQué hace
labelTypenone, selected o all; un nombre oculto sigue siendo el nombre accesible
extendedun rail ancho, con el texto junto al ícono
leading, trailingun widget antes o después de los destinos
groupAlignment-1 arriba, 0 al centro, 1 abajo
NavigationRailDestination(href:)un destino que es un enlace, sin estado

NavigationRailTheme, o ThemeData(navigationRailTheme:), define los valores por omisión de los rails que contiene.

Link

Cualquier widget como enlace: interno o externo, en otra pestaña, o marcado como página actual.
Externo
Otra pestaña
Página actual

Convierte cualquier widget en un enlace sin agregar nada alrededor; current: true marca el enlace de la página actual. Los botones y los ListTile aceptan href directamente.

Un Column centra a sus hijos y cada enlace mide lo que su texto. Para una lista de enlaces alineados al inicio, usa CrossAxisAlignment.stretch:

Column(
  crossAxisAlignment: CrossAxisAlignment.stretch,
  children: [
    Link(
      href: const RouteUrl('/coffee'),
      child: const Padding(
        padding: EdgeInsets.all(10),
        child: Text('Coffee', textAlign: TextAlign.start),
      ),
    ),
  ],
)
