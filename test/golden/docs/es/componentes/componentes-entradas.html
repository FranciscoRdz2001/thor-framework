TextField

Un campo de texto: ayuda, ícono, error y habilitado.
Ayuda
Ícono
Error
Habilitado

Un campo de texto con etiqueta, ayuda e ícono. Cada tecla llega a onChanged.

ParámetroQué hace
decorationInputDecoration: labelText, hintText, helperText, errorText, prefixIcon, suffixIcon, prefixText, suffixText, counterText, filled, isDense
onChanged, onSubmittedel método que recibe el texto, en cada tecla o al pulsar Enter
controllerun TextEditingController del ViewModel, para leer o cambiar el texto desde un método
keyboardType, obscureTextel teclado del teléfono (emailAddress, phone, number) y el texto oculto de una contraseña
maxLines, minLinesvarias líneas; maxLines: null crece mientras se escribe
initialValue, enabledel valor inicial; false bloquea el campo

Los demás atributos (readOnly, maxLength, textInputAction, autofillHints) están en Formularios.

TextFormField

Las reglas del esquema: deja el campo mal y pulsa Enviar.

Correo
Nombre
Ayuda

El campo de un formulario: valida con sus reglas y muestra el mensaje de la primera que falla. Validator incluye required, email, minLength, maxLength, pattern, min, max y custom.

Con un campo de un FormSchema (TextFormField(field: SignUp.email)), el servidor revisa las mismas reglas al enviar (Formularios).

Autocomplete

Un campo que sugiere opciones: la lista, hacia dónde se abre y su alto.
Lista
Frutas
Colores
Se abre
Abajo
Arriba
Alto del panel
200 px

Un campo que sugiere opciones mientras el usuario escribe, en un panel que queda por encima del resto de la página. Las flechas mueven el resaltado, Enter elige y Esc cierra; sin JavaScript es un campo de texto.

Un lector de pantalla anuncia cuántas opciones hay cada vez que cambian. Estos textos se traducen con tres parámetros:

Autocomplete<String>(
  resultsLabel: '{count} results',
  oneResultLabel: '1 result',
  noResultsLabel: 'No results',
  optionsBuilder: (value) =>
      fruits.where((f) => f.contains(value.text.toLowerCase())),
)
ParámetroQué hace
optionsBuilderlas opciones; se llama una vez, al construir la página
displayStringForOptionel texto de una opción: lo que se muestra y lo que se compara
onSelectedel método que recibe la opción (String, número, bool o enum)
optionsViewOpenDirection, optionsMaxHeighthacia dónde abre el panel y su alto máximo
semanticLabel, menuStyleel nombre accesible del campo y el aspecto del panel
Diferencia con Flutter

optionsBuilder no puede ser async, y ninguna opción queda resaltada hasta que el usuario mueve el resaltado, así Enter envía lo escrito.

Sugerencias del servidor

Para opciones que busca el servidor, RawAutocomplete muestra en el panel una lista del ViewModel:

RawAutocomplete<String>(
  optionsBuilder: (v) => const [],
  textEditingController: search.box, // a TextEditingController of the view model
  focusNode: search.focus,
  fieldViewBuilder: (context, controller, focus, submit) =>
      TextField(controller: controller, focusNode: focus, onChanged: search.type),
  optionsViewBuilder: (context, onSelected, options) => Watch.list(
    search.names,
    itemKey: search.nameOf,
    each: (row) => Semantics(
      role: SemanticsRole.option,
      child: row.link(search.hrefOf, child: row.text(search.nameOf)),
    ),
  ),
)

Paleta de comandos (en línea)

Para una paleta ⌘K dentro de un dialog, la lista va en el flujo, junto al campo, y no en un panel flotante:

RawAutocomplete<String>(
  inline: true,          // list in the flow, visible while there are options
  highlightFirst: true,  // the first option is active: Enter picks it
  optionsBuilder: (v) => const [],
  fieldViewBuilder: (context, controller, focus, submit) =>
      TextField(controller: controller, focusNode: focus),
  optionsViewBuilder: (context, onSelected, options) => Watch.list(
    palette.hits,
    itemKey: palette.idOf,
    each: (row) => Semantics(role: SemanticsRole.option, child: row.text(palette.nameOf)),
  ),
)

Con inline, Esc no lo toma la lista: el dialog se cierra con una sola pulsación. Teclas: ↑/↓ dan la vuelta, AvPág/RePág mueven una página, y Ctrl o ⌘ con Inicio/Fin van a la primera o última opción (Inicio/Fin sin modificador siguen moviendo el cursor del campo, como en el patrón combobox de la WAI-ARIA). highlightFirst también sirve sin inline.

Diferencia con Flutter

inline y highlightFirst no existen allí (RawAutocomplete siempre resalta la primera opción y la muestra en un overlay).

Campos de fecha

El campo del navegador o el campo con calendario. Meses, días, primer día de la semana y dígitos salen del idioma de la página.
Campo
Nativo
Calendario
Permite vacío

InputDatePickerFormField es el campo de fecha del navegador. DatePickerFormField le agrega un botón que abre un calendario y entrega la fecha al ViewModel con onDateChanged.

El calendario usa el idioma de la página: nombres, primer día de la semana, dígitos y dirección (Idiomas).

Diferencia con Flutter

No existe showDatePicker(context): el calendario está en la página. Usa DatePickerFormField, o un DatePickerDialog que se abre con DialogTrigger (Avisos).

Burbuja con el valor

SliderThemeData(showValueIndicator:) dibuja una burbuja sobre el pulgar que lo sigue al arrastrar. label es su texto: un {} se reemplaza por el valor en vivo.

import 'package:thor_ui/thor_ui.dart';

class SliderBubbleDemo extends StatelessWidget {
  const SliderBubbleDemo({super.key});

  @override
  Widget build(BuildContext context) => Theme(
    data: ThemeData(
      sliderTheme: const SliderThemeData(
        showValueIndicator: ShowValueIndicator.alwaysVisible,
      ),
    ),
    child: const SizedBox(
      width: 320,
      child: Slider(
        value: 50,
        min: 10,
        max: 100,
        divisions: 9,
        label: '{}k',
        semanticLabel: 'Visitas al mes',
      ),
    ),
  );
}
