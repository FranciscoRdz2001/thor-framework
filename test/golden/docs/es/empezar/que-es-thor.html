Qué es Thor

Thor renderiza widgets de Flutter como HTML semántico y CSS en el servidor. Aquí decides si encaja con tu app.

Un widget, una página

Escribes un StatelessWidget como en Flutter. Thor ejecuta su build en el servidor y envía al navegador un elemento HTML con su clase CSS.

Hello, Thor

Flutter widgets in, semantic HTML out.
import 'package:thor_ui/thor_ui.dart';

class WelcomeCard extends StatelessWidget {
  const WelcomeCard({super.key});

  @override
  Widget build(BuildContext context) => Container(
    width: 280,
    padding: const EdgeInsets.all(20),
    decoration: BoxDecoration(
      color: ThemeColor.surfaceContainer,
      borderRadius: BorderRadius.circular(16),
    ),
    child: Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      spacing: 8,
      children: [
        const Semantics(
          headingLevel: 2,
          child: Text('Hello, Thor', style: ThemeText.titleLarge),
        ),
        const Text('Flutter widgets in, semantic HTML out.'),
        FilledButton(onPressed: () {}, child: const Text('Get started')),
      ],
    ),
  );
}

Qué corre dónde

El código de los widgets corre en el servidor; el navegador hace el layout y actualiza solo lo que cambia.

Parte de la appCorre enQué hace
build de cada widgetservidorrenderiza el HTML y el CSS, una vez por petición
load de cada páginaservidorcarga los datos antes de renderizar
layout, scroll y animacionesnavegadorse aplican con CSS, sin JavaScript
ViewModel (ThorState)navegadoractualiza lo que cambia sin recargar la página

El JavaScript solo llega a las páginas que usan un ViewModel. El detalle está en Qué corre dónde.

Thor o Flutter web

Elige Thor si…Elige Flutter web si…
el sitio debe indexarse: una tienda, un blog, documentaciónla app dibuja cada píxel: un editor, un juego
necesitas texto seleccionable, enlaces, zoom y formularios nativosnecesitas el mismo render en móvil, escritorio y web
la primera pantalla debe mostrar contenido sin esperar al JavaScriptla app ya existe en Flutter y no conviene reescribirla

Para combinar los dos, Flutter embebido coloca una app de Flutter dentro de una región de la página.
