Instalación

Instala el comando thor, crea una app y ábrela en el navegador. Necesitas Dart y un editor.

Nota

Thor está en la versión 0.1 y todavía no se publica en pub.dev. El comando thor se instala desde una copia local del repositorio, y cada proyecto nuevo usa esa copia.

Instalar y crear una app

Clona el repositorio, activa el comando y crea la app. thor dev la sirve en http://localhost:4300, o en el siguiente puerto libre.

Edit lib/modules/home/pages/home_page.dart and save: the page updates by itself.

git clone https://github.com/FranciscoRdz2001/thor-framework.git thor

cd my_app
thor dev

Archivos del proyecto

  • my_app/
    • .github/workflows/ci.ymlintegración continua: formato, análisis y pruebas
    • bin/
      • server.dartel servidor
    • lib/
      • app.dartel tema y la app
      • env.dartlas variables de entorno
      • router.dartla tabla de rutas
      • shell/el marco de las páginas y la página de error
      • core/lo que comparten varios módulos
      • modules/
        • home/la página de inicio, su ruta y un contador de ejemplo
    • web/archivos públicos
    • test/pruebas
    • pubspec.yaml

La organización completa está en Estructura del proyecto.

Configurar el editor

QuéCómo
Dartla extensión de Dart de tu editor (VS Code, Cursor, IntelliJ, Zed)
Reglas de Thorya activas: thor create las agrega a analysis_options.yaml y el editor marca lo que no funciona en el navegador, con su código THOR-*
Del navegador al códigocon thor dev, Alt+clic (Option en Mac) sobre un elemento abre el archivo que lo construyó; THOR_EDITOR=cursor elige el editor

Variables de entorno

lib/env.dart declara las variables con su tipo; los valores van en .env, en la raíz de la app, que thor create agrega a .gitignore.

.env
API_URL=https://api.example.com
SESSION_SECRET=a-long-key-of-at-least-32-characters

thor dev y thor preview leen .env. Si falta una variable, el servidor no arranca y lista todas las que faltan (THOR-P011). Los tipos y la protección de secretos están en Sesión y seguridad.

Integración continua

thor create escribe .github/workflows/ci.yml, que instala thor y ejecuta el formato, dart analyze --fatal-infos y thor test. CI solo puede instalar Thor desde un repositorio: crea el proyecto con --git <url> o apunta la dependencia de pubspec.yaml a un repositorio.

Consejo

thor analyze y thor format --check ejecutan en tu equipo las mismas comprobaciones que CI.

Comandos frecuentes

ComandoQué hace
thor devejecuta la app y la actualiza en cada cambio
thor testejecuta las pruebas
thor analyzeanaliza el proyecto con las reglas de Thor
thor buildcompila la versión de producción
thor previewsirve la versión compilada en http://localhost:4400
thor doctor --fixrevisa el SDK y el proyecto, y aplica las correcciones seguras

Cada comando y sus opciones están en El comando thor.
