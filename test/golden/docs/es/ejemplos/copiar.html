Botón de copiar

Un botón que copia un texto y lo confirma con una marca de verificación que dura un momento.

  • FlutterAnimatedSwitcher
  • Thorun AnimationController en un ThorState
thor create my_app

Código de la app
class CopyViewModel extends ThorState {
  final done = AnimationController(
    duration: Duration(milliseconds: 1800),
  );
 
  void copy() {
    Clipboard.setData(ClipboardData(text: 'thor create my_app'));
    done.reset();
    done.animateTo(1.0, duration: Duration(milliseconds: 1800));
  }
}
 
// 8 % in, 84 % shown, 8 % out.

Botón de copiar

Al copiar el comando, el ícono se vuelve una marca de verificación durante un momento y luego regresa.
Cambio
Fundido
Escala
Giro
Se queda
1800 ms

Un solo AnimationController del ViewModel (ThorState) mueve el ícono, la marca y el texto sobre la misma línea de tiempo, con el cambio en el primer y el último 8 %. No hay un temporizador que cancelar: pulsar otra vez reinicia el ciclo. Con la preferencia de reducir el movimiento, el cambio es instantáneo.
