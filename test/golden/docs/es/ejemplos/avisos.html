Varios avisos a la vez, el más reciente delante y los anteriores detrás, que entran y salen por el mismo borde.

  • FlutterAnimatedPositioned por aviso
  • ThorAnimatedSlide, AnimatedScale y AnimatedOpacity

Código de la app
class ToastViewModel extends ThorState {
  final shown = state(1);
 
  int shownCount() => shown.value;
  bool canShow() => shown.value < 3;
 
  void show() => shown.value += 1;
  void dismiss() => shown.value -= 1;
}
 
final toasts = ToastViewModel();
 
// For each toast k, in Watch(toasts.shownCount, count: 4, builder: (shown) => …):
// depth: 0 is the newest, in front.
final depth = shown - 1 - k;
final hidden = k >= shown;
final dy = hidden ? 1.0 : -0.28 * depth;
 
AnimatedOpacity(
  opacity: hidden ? 0 : 1 - 0.25 * depth,
  duration: Duration(milliseconds: 300),
  curve: Curves.easeOut,
  child: AnimatedScale(
    scale: 1 - 0.05 * depth,
    duration: Duration(milliseconds: 300),
    curve: Curves.easeOut,
    child: AnimatedSlide(
      offset: Offset(0, dy),
      duration: Duration(milliseconds: 300),
      curve: Curves.easeOut,
      child: toast(k),
    ),
  ),
)

Pila de avisos

Cada aviso entra por el borde que elijas, el más nuevo queda delante y los anteriores se encogen y se desvanecen detrás. Al descartar, el aviso sale por donde entró.

Cada aviso depende solo de su profundidad: cuántos avisos tiene delante. Al llegar uno nuevo, los demás cambian de profundidad y se acomodan a la vez; al descartarlo, vuelve por donde entró. Son transiciones implícitas, así un aviso que llega a mitad de una animación no la reinicia. Para que se cierren solos, usa un Timer en el ViewModel (ThorState).
