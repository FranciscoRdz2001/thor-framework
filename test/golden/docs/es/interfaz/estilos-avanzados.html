Estilos avanzados

Aplica lo que ningún widget expresa: posición fija, desplazamiento interno, unidades de la ventana, clases de tus componentes y HTML que no viene de widgets.

Qué usar, en orden

Empieza por arriba y baja un nivel solo cuando el anterior no alcanza.

1
Props del widget
primero

Casi todo: Container(padding:, decoration:), Text(style:), Row(spacing:). Es lo que escribirías en Flutter.

2
Wrappers

Para decorar sin agregar elementos: Padding, Opacity, Transform, BackdropFilter (desenfoca lo que hay detrás), ClipRRect, Link. Se funden en el elemento de su hijo.

3
Variantes con .when()

Lo que cambia por ancho, estado, tema o tamaño del contenedor: EdgeInsets.all(16).when(medium: EdgeInsets.all(32)). Ver Tema y estilos.

4
StyleProps en Styled

Lo que ningún widget expresa: posición fija, desplazamiento interno, unidades como 100.dvh y números que cambian con .when(). Ver StyleProps en Styled.

5
Hojas de estilo propias

Las clases de tus componentes y los estados que ningún widget expresa. Ver Hojas de estilo propias.

6
Styled(descendants:)
último recurso

HTML que no construye ningún widget, como markdown o el contenido de un CMS. Ver HTML sin widgets.

Cada nivel tiene tipos: el analizador detecta un error tipográfico, el editor autocompleta y los valores que vienen de tus datos se escapan antes de llegar a la página.

StyleProps en Styled

Styled(style:) aplica un StyleProps al elemento de su hijo, sin agregar otro. En la lista, cada letra queda fija arriba (BoxPosition.sticky) hasta que la siguiente la empuja.

    position: BoxPosition.sticky(top: 0.px),
    zIndex: 20,
    maxHeight: 100.dvh - 72.px,
    overflowY: Overflow.auto,
  ),
  child: TableOfContents(),

BoxPosition recibe sus distancias como Length: BoxPosition.fixed(bottom: 16.px, right: 16.px). Dentro de un Stack, usa Positioned como en Flutter.

Styled no reemplaza a los widgets. Lo que un widget ya expresa (padding, decoration, color, un número fijo) va en ese widget; el lint widget_props_in_styled lo señala.

// WRONG (widget_props_in_styled): padding belongs to a widget
Styled(style: StyleProps(padding: EdgeInsets.all(12)), child: child)

// RIGHT
Padding(padding: EdgeInsets.all(12), child: child)

// Hover each tile (or press it on a touch screen, where hover doesn't
// exist): the values change with .when(hover:, pressed:) and Styled's
// duration turns the change into a transition.
class HoverEffects extends StatelessWidget {
  const HoverEffects({super.key});

  @override
  Widget build(BuildContext context) => Wrap(
    spacing: 12,
    runSpacing: 12,
    children: [
      _Tile(
        'turns',
        const StyleProps(turns: 0).when(
          hover: const StyleProps(turns: -0.02),
          pressed: const StyleProps(turns: -0.02),
        ),
      ),
      _Tile(
        'offset + scale',
        const StyleProps(offset: Offset.zero, scale: 1).when(
          hover: const StyleProps(offset: Offset(0, -6), scale: 1.04),
          pressed: const StyleProps(offset: Offset(0, -6), scale: 1.04),
        ),
      ),
      _Tile(
        'blur',
        const StyleProps(blur: 3).when(
          hover: const StyleProps(blur: 0),
          pressed: const StyleProps(blur: 0),
        ),
      ),
    ],
  );
}

class _Tile extends StatelessWidget {

Unidades

Las props de Flutter miden en píxeles lógicos (double): EdgeInsets.all(16) son 16 píxeles. Para lo que se mide de otra forma, como el alto de la ventana o una fracción del padre, existe Length.

16.px            // 16 logical pixels
50.percent       // half of the parent
1.5.em           // 1.5 × the element's font size
1.rem            // 1 × the page's font size
60.ch            // about 60 characters: a good reading width
100.vw           // the window's width
100.dvh          // the window's height now (follows a phone's bars)
96.px
50.percent
8.rem
20.ch
12.vw

import 'package:thor_ui/thor_ui.dart';

const _accent = ThemeColor.primary;
const _mono = TextStyle(
  fontFamily: 'IBM Plex Mono',
  fontFamilyFallback: ['ui-monospace', 'monospace'],
  fontSize: 12,
);

class UnitBars extends StatelessWidget {
  const UnitBars({super.key});

  @override
  Widget build(BuildContext context) => SizedBox(
    // 460 px wide, never wider than its parent (a phone), like in Flutter.
    width: 460,
    child: Column(
      crossAxisAlignment: CrossAxisAlignment.stretch,
      spacing: 10,
      children: [
        for (final (label, length) in [
          ('96.px', 96.px),
          ('50.percent', 50.percent),
          ('8.rem', 8.rem),
          ('20.ch', 20.ch),
          ('12.vw', 12.vw),
          (
            'Length.clamp(4.rem, 15.vw, 100.percent)',
            Length.clamp(4.rem, 15.vw, 100.percent),
          ),
        ])
          Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            spacing: 4,
            children: [
              Text(label, style: _mono),
              // Min and max width: the bar measures exactly `length`.
              Styled(
                style: StyleProps(minWidth: length, maxWidth: length),
                child: Container(
                  height: 10,
                  decoration: BoxDecoration(
                    color: _accent,
                    borderRadius: BorderRadius.circular(5),
                  ),
                ),
              ),
            ],
          ),
      ],
    ),
  );
}

Código

Las operaciones combinan unidades y los límites se escriben con min, max y clamp:

100.dvh - 48.px                          // the window minus a bar
(100.vw - 2.rem) / 3                     // a third of the window, minus margins
Length.min([100.percent, 720.px])        // the parent, at most 720 px
Length.clamp(1.rem, 2.vw + 1.rem, 3.rem) // grows with the window, with limits
card.gap.px * 2                          // follows a state field

Length.px(16), Length.min, Length.max y Length.clamp son const; 16.px es la forma corta.

Un elemento con containerType: ContainerType.size es una caja que mide: adentro, 100.cqw y 100.cqh son su ancho y su alto (también cqi, cqb, cqmin, cqmax). Esa caja no crece con su contenido: necesita un alto propio (Expanded, heightLength). Ratio.of(a, b) es a entre b (cuántas veces cabe b en a), un número que calcula el navegador; con StyleProps(scaleRatio:) escala una caja para que quepa en su contenedor, sin JS ni puntos de corte:

Expanded(
  child: Styled(
    style: const StyleProps(containerType: ContainerType.size),
    child: SizedBox.expand( // the stage
      child: Styled(
        style: StyleProps(
          transformOrigin: Alignment.topLeft,
          scaleRatio: Ratio.min([
            Ratio.value(1), // never above 100%
            Ratio.of(100.cqh, 844.px),
            Ratio.of(100.cqw, 390.px),
          ]),
        ),
        child: device, // 390 x 844
      ),
    ),
  ),
)

Styled se funde en el elemento de su hijo, así que el escenario es un widget con elemento propio (aquí SizedBox.expand): las unidades cq miden un ancestro, nunca al elemento mismo.

Diferencia con Flutter

Flutter calcula el layout en Dart y no necesita unidades. En la web lo calcula el navegador, y a veces el valor es «el alto de la ventana» o «la mitad del padre». Length aparece solo donde Flutter no tiene equivalente.

Hojas de estilo propias

Para las clases de tus componentes, escribe reglas con css() y dales valores con .props(), el mismo StyleProps de arriba. La hoja de un componente va con él, en css.components:

import 'package:thor_ui/html.dart' show css;
import 'package:thor_ui/thor_ui.dart';

class ProductCard extends StatelessWidget {
  const ProductCard({super.key});

  static final styles = css.components([
    css('.product-card', [
      css('&').props(const StyleProps(padding: EdgeInsets.all(12))),
      css('&:hover').props(const StyleProps(offset: Offset(0, -2))),
    ]),
  ]);

  @override
  Widget build(BuildContext context) =>
      Styled(classes: const ['product-card'], child: const Text('Cold brew'));
}

Styled(classes:) agrega la clase al elemento del hijo. Una hoja para toda la app se pasa una vez en ThorApp.router(styles:), y una que solo usan las rutas de un grupo va en Group(styles:), para que las demás páginas no la descarguen:

lib/styles.dart
import 'package:thor_ui/html.dart' show css;
import 'package:thor_ui/thor_ui.dart';

final List<StyleRule> appStyles = [
  css('.card', [
    css('&').props(StyleProps(
      padding: const EdgeInsets.all(12),
      decoration: BoxDecoration(borderRadius: BorderRadius.circular(16)),
    )),
    css('&:hover').props(const StyleProps(offset: Offset(0, -2))),
  ]),
  WindowSizeClass.medium.media([
    css('.card').props(const StyleProps(padding: EdgeInsets.all(16))),
  ]),
];

Una regla varía con su selector y con WindowSizeClass.media; .when() es para los widgets.

Un ancho que no es una clase de tamaño va en una hoja con css.minWidth(920, [...]) o css.maxWidth(919.98, [...]). Una hoja es un solo texto para todas las peticiones, así que WindowSizeClass.media usa los anchos por defecto salvo que reciba los de la app: guárdalos en una const y pásala al tema y a la hoja.

const siteBreakpoints = Breakpoints(medium: 640, expanded: 768, large: 1024);
// ThemeData(breakpoints: siteBreakpoints)
WindowSizeClass.medium.media(breakpoints: siteBreakpoints, [...]);
css.minWidth(920, [css('.card').props(const StyleProps(padding: EdgeInsets.all(20)))]);

Los widgets (.when(...)) ven las cuatro clases de tamaño del tema; para cualquier otro ancho de su propia caja usa .when(container: {920: …}).

Importante

Las reglas de tus hojas ganan siempre a los estilos de los widgets. Úsalas para clases propias, no para cambiar todos los elementos de un tipo, y no pongas una transición sobre un elemento que ya anima un Animated*: la reemplaza.

La hoja de un componente (css.components) queda debajo de los props propios de los elementos: .fila:hover .nombre no le gana al fontWeight del Text de adentro. Para un descendiente que cambia con el estado de un ancestro (:hover, :has([aria-current]), [open]) usa css.states, que va después:

import 'package:thor_ui/html.dart' show css;
import 'package:thor_ui/thor_ui.dart';

final styles = css.states([
  css('.tree-row:has(a[aria-current]) .tree-name')
      .props(const StyleProps(textStyle: TextStyle(fontWeight: FontWeight.w600))),
]);

Hojas de estilo por nivel

Cada hoja pertenece a un nivel (tema, componentes, app, módulo o página); Compilar y publicar explica cómo compartirlas entre páginas para que el navegador las guarde en caché.

HTML sin widgets

El markdown renderizado o el contenido de un CMS no viene de widgets, así que no tiene props. Styled(descendants:) le da estilo con tipos, limitado al elemento que lo envuelve.

Styled(
  descendants: {
    '> * + *': const StyleProps(margin: EdgeInsets.only(top: 14)),
    'h2': const StyleProps(
      textStyle: TextStyle(fontSize: 22, fontWeight: FontWeight.w700),
      margin: EdgeInsets.only(top: 36),
    ),
    'a': const StyleProps(
      textStyle: TextStyle(decoration: TextDecoration.underline),
    ),
    'img': StyleProps(maxWidth: 100.percent),
  },
  child: DefaultTextStyle(
    style: const TextStyle(fontSize: 16, height: 1.7),
    child: Container(child: html.RawText(markup)),
  ),
)

Release notes

Styles are typed: 16.px, StyleProps and more.

  • Units on the numbers
  • Typed web props
import 'package:thor_ui/html.dart' as html;
import 'package:thor_ui/thor_ui.dart';

const _muted = ThemeColor.onSurfaceVariant;
const _tint = ThemeColor.secondaryContainer;
const _mono = TextStyle(
  fontFamily: 'IBM Plex Mono',
  fontFamilyFallback: ['ui-monospace', 'monospace'],
  fontSize: 12,
);

// HTML no widget builds (rendered markdown, a CMS body): styled by tag,
// scoped to this element.
class ReleaseNotes extends StatelessWidget {
  const ReleaseNotes({super.key});

  @override
  Widget build(BuildContext context) => Styled(
    descendants: {
      'h3': const StyleProps(
        textStyle: TextStyle(fontSize: 17, fontWeight: FontWeight.w700),
        // Only these two sides: the others keep the browser's.
        margin: EdgeInsetsGeometry.sides(
          top: Length.zero,
          bottom: Length.px(6),
        ),
      ),
      'li + li': const StyleProps(
        margin: EdgeInsetsGeometry.sides(top: Length.px(4)),
      ),
      'p': const StyleProps(
        textStyle: TextStyle(color: _muted, height: 1.6),
        margin: EdgeInsets.only(bottom: 8),
      ),
      'a': const StyleProps(
        textStyle: TextStyle(
          color: ThemeColor.onSurface,
          decoration: TextDecoration.underline,
        ),
      ),
      'code': StyleProps(
        textStyle: _mono,
        padding: const EdgeInsets.symmetric(horizontal: 4, vertical: 1),
        decoration: BoxDecoration(
          color: _tint,
          borderRadius: BorderRadius.circular(4),
        ),
      ),
      'ul': const StyleProps(
        padding: EdgeInsets.only(left: 18),
        margin: EdgeInsets.zero,
      ),
    },
    // 340 px wide, never wider than its parent (a phone), like in Flutter.
    child: const SizedBox(
      width: 340,
      child: html.RawText(
        '<h3>Release notes</h3>'
        '<p>Styles are typed: <code>16.px</code>, '
        '<code>StyleProps</code> and <a href="#">more</a>.</p>'
        '<ul><li>Units on the numbers</li><li>Typed web props</li></ul>',
      ),
    ),
  );
}

Código

Cada clave es un selector dentro del elemento (h2, a:hover, pre code) y cada valor, un StyleProps sin variantes. El texto del contenedor sigue yendo por su widget (DefaultTextStyle).

Sin raw: para lo común: EdgeInsetsGeometry.sides pone solo los lados que recibe (los otros quedan como los deja el navegador), y un Length en em sigue al texto de alrededor.

Styled(
  descendants: {
    '> :first-child': StyleProps(
      margin: EdgeInsetsGeometry.sides(top: Length.zero),
    ),
    ':not(pre) > code': StyleProps(
      textStyle: TextStyle(fontSizeLength: 0.9.em, heightLength: 1.25.em),
    ),
    'h2': StyleProps(textStyle: TextStyle(fontWeight: FontWeight(650))),
    'img.right': StyleProps(float: BoxFloat.right),
  },
  child: Container(child: html.RawText(markup)),
)

Patrones con degradados

Un degradado con tile: se repite en mosaico: un fondo punteado o a rayas sin imágenes.

BoxDecoration(
  color: const Color(0xFFECEEF3),
  gradient: RadialGradient(
    colors: [const Color(0xFF4F46E5).withValues(alpha: 0.16), const Color(0x00000000)],
    stops: const [0.125, 0.125],      // a 1px dot (0.125 of the 8px radius)
    tile: const Size.square(16),      // every 16px
  ),
)
import 'package:thor_ui/thor_ui.dart';

const _line = ThemeColor.outlineVariant;

// A gradient repeated in tiles: dots and stripes, no image.
class TiledPatterns extends StatelessWidget {
  const TiledPatterns({super.key});

  @override
  Widget build(BuildContext context) => const Row(
    spacing: 12,
    children: [
      _Pattern(
        RadialGradient(
          colors: [Color(0x664F46E5), Color(0x00000000)],
          stops: [0.2, 0.2],
          tile: Size.square(14),
        ),
      ),
      _Pattern(
        LinearGradient(
          begin: Alignment.topLeft,
          end: Alignment.bottomRight,
          colors: [
            Color(0x334F46E5),
            Color(0x334F46E5),
            Color(0x00000000),
            Color(0x00000000),
          ],
          stops: [0, 0.5, 0.5, 1],
          tile: Size.square(12),
        ),
      ),
    ],
  );
}

class _Pattern extends StatelessWidget {
  const _Pattern(this.gradient);

  final Gradient gradient;

  @override
  Widget build(BuildContext context) => Container(
    width: 140,
    height: 90,
    decoration: BoxDecoration(
      gradient: gradient,
      border: Border.all(color: _line),
      borderRadius: BorderRadius.circular(12),
    ),
  );
}
