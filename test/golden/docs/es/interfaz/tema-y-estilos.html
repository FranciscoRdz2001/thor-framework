Diferencia con Flutter

ColorScheme.fromSeed no existe. Escribe los roles que cambian (ColorScheme.light(primary: …)); el resto toma los valores de Material 3.

Roles de color

Cada rol del colorScheme tiene un valor en el tema claro y otro en el oscuro. Estos son los que más se usan:

RolUso
primaryacciones principales, enlaces y foco
onPrimarytexto e íconos sobre primary
surfaceel fondo de la página
onSurfaceel texto de la página
surfaceContainertarjetas y paneles
errorerrores y acciones destructivas

La referencia de la API lista el resto de los roles de ColorScheme.

Colores propios

Declara cada color de tu marca con ColorToken: es un Color const que lleva su valor claro y su valor oscuro.

abstract final class AppColors {
  static const band = ColorToken('band',
      light: Color(0xFFF7F6F2), dark: Color(0xFF22252A));
  static const muted = ColorToken('muted',
      light: Color(0xFF697077), dark: Color(0xFFA6ACB3));
  static const values = [band, muted];
}

final light = ThemeData(tokens: AppColors.values);
final dark = ThemeData(
    colorScheme: const ColorScheme.dark(), tokens: AppColors.values);

Container(color: AppColors.band)       // follows the theme

Dos tokens con el mismo nombre son el error THOR-R021. Para escalas de 50 a 950 existe ColorScale, y Colors.blue.shade700 funciona como en Flutter.

import 'package:thor_ui/thor_ui.dart';

// The dark switch is a state here because the docs page has one theme; in an
// app it is the system's mode or a ThemeToggle. What matters: the boxes read
// Theme.of(context) and follow, with nothing rebuilt by hand.
class ThemeSwitchViewModel extends ThorState {
  final dark = state(false);

  bool isDark() => dark.value;
  void setDark(bool on) => dark.value = on;
}

final themeSwitch = ThemeSwitchViewModel();

class ThemeSwitchExample extends StatelessWidget {
  const ThemeSwitchExample({super.key});

  @override
  Widget build(BuildContext context) => Column(
    mainAxisSize: MainAxisSize.min,
    crossAxisAlignment: CrossAxisAlignment.start,
    spacing: 12,
    children: [
      Row(
        mainAxisSize: MainAxisSize.min,
        spacing: 8,
        children: [
          Switch(
            value: false,
            onChanged: themeSwitch.setDark,
            semanticLabel: 'Dark mode',
          ),
          const Text('Dark mode'),
        ],
      ),
      Watch(
        themeSwitch.isDark,
        builder: (dark) => Theme(
          data: ThemeData(
            colorScheme: dark
                ? const ColorScheme.dark()
                : const ColorScheme.light(),
          ),
          child: const _Swatches(),
        ),
      ),
    ],
  );
}

class _Swatches extends StatelessWidget {
  const _Swatches();

  Widget build(BuildContext context) {

      ),
    );
  }
}

La elección del usuario se guarda en el navegador y se aplica antes de mostrar la página: al recargar no hay parpadeo. Requiere navegadores de 2024 (Chrome 123, Safari 17.5, Firefox 120).

Importante

Un Color literal es el mismo en los dos temas. Para que un color siga al modo oscuro, léelo del tema (ThemeColor.primary) o declara un ColorToken.

Leer el tema en código

Theme.of(context).colorScheme devuelve colores que siguen al modo oscuro, también con withValues(alpha:).

final scheme = Theme.of(context).colorScheme;
Container(
  color: scheme.primary.withValues(alpha: 0.15),
  child: Text('x', style: TextStyle(color: scheme.onSurface)),
)
ExpresiónResultado
scheme.primary en un color, borde o textosigue al modo oscuro
scheme.primary.withValues(alpha: .15)sigue al modo oscuro
.value, .red, .opacity, Color.alphaBlend (también en Color.css y colores con .when(); hasChannels lo dice)error THOR-R023
scheme.primary.fallback!.valueel color de un solo modo
scheme.brightnessel del tema
Diferencia con Flutter

El servidor renderiza la página una vez y no conoce el modo del usuario, así que Theme.of no devuelve un color fijo. Para elegir entre dos colores usa .when(dark: …).

Un estilo de texto

copyWith cambia el tamaño y el peso de un rol del TextTheme; el resto del estilo sigue al tema.
Tamaño
28 px
Peso
w600

Para que un rol crezca en pantallas anchas, da una variante al TextTheme entero:

textTheme: textTheme.when(
  medium: textTheme.copyWith(displayLarge: const TextStyle(fontSize: 60)),
),

Para un tamaño que crece con la ventana, TextStyle acepta además un Length (Unidades):

const TextStyle(
  fontSize: 40,                                   // the number Dart reads
  fontSizeLength: Length.clamp(Length.px(40), Length.vw(5), Length.px(72)),
  letterSpacingLength: Length.em(-0.02),
)

Fuentes

Cada FontFace es un archivo de fuente de la app: el equivalente de la sección fonts: del pubspec.yaml de Flutter.

fonts: [
  // A variable font: every weight in one file.
  FontFace('Inter', url: '/fonts/inter.woff2',
      weight: FontWeight.w100, maxWeight: FontWeight.w900, preload: true),
  // One file per weight or style.
  FontFace('Mono', url: '/fonts/mono-400.woff2'),
  FontFace('Mono', url: '/fonts/mono-500.woff2', weight: FontWeight.w500),
],
OpciónEfecto
display:qué se ve mientras carga; FontDisplay.swap (por defecto) nunca oculta el texto
preload: truedescarga el archivo antes; úsalo solo en la fuente de la primera pantalla
thor fonts subsetrecorta la fuente a los caracteres que usa la app
thor fonts metricsmide un FontFallback con las mismas proporciones, para que el texto no salte

Los archivos van en web/ de la app. Si vienen de un paquete, el paquete los declara y thor dev los copia.

// One place for the look of each widget kind: no widget below repeats it.
final _theme = ThemeData(
  cardTheme: const CardThemeData(
    color: _tint,
    elevation: 0,
    shape: RoundedRectangleBorder(
      borderRadius: BorderRadius.all(Radius.circular(16)),
      side: BorderSide(color: _line),
    ),
  ),
  chipTheme: const ChipThemeData(
    backgroundColor: _card,
    shape: StadiumBorder(),
    side: BorderSide(color: _line),
  ),
  filledButtonTheme: const FilledButtonThemeData(
    style: ButtonStyle(
      backgroundColor: WidgetStatePropertyAll(_accent),
      foregroundColor: WidgetStatePropertyAll(ThemeColor.onPrimary),
      shape: WidgetStatePropertyAll(
        RoundedRectangleBorder(
          borderRadius: BorderRadius.all(Radius.circular(8)),
        ),

);

class ComponentThemes extends StatelessWidget {

Código

Existen los temas de Flutter para tarjetas, chips, botones, campos, divisores, diálogos, barras, listas, avisos, menús, pestañas y controles de selección: cardTheme, chipTheme, filledButtonTheme, iconButtonTheme, inputDecorationTheme, dialogTheme, appBarTheme, listTileTheme, snackBarTheme, tabBarTheme, checkboxTheme, switchTheme y los demás. Gana el parámetro del widget, después el tema y al final el valor por defecto.

Cada XThemeData lleva los campos de Flutter que el navegador puede aplicar; la documentación de cada clase lista los que faltan. Theme.provide(data:) cambia el tema de un subárbol, y un ThemeExtension guarda valores propios de tu marca.

Variantes con .when()

Lo que cambia por ancho, estado o tema es un valor con .when(). La variante solo lleva lo que cambia; el resto se hereda del valor base.

Container(padding: const EdgeInsets.all(24).when(medium: EdgeInsets.all(32)))

BoxDecoration(color: ThemeColor.surface.when(hover: ThemeColor.surfaceContainer))

VarianteSe aplica
medium, expanded, large, extraLargedesde 600, 840, 1200 y 1600 px de ancho de ventana (las clases de tamaño de Material 3)
darkcon el tema oscuro
hover, focused, pressedal pasar el puntero, con foco de teclado, mientras se presiona
opencon el <details> más cercano abierto (un ExpansionTile: su cabecera y su contenido); uno anidado decide por lo suyo
groupHoveral pasar el puntero sobre el HoverGroup más cercano
groupHovers: {'card': …}lo mismo, para el HoverGroup(name: 'card') más cercano
container: {400: …}cuando el LayoutScope más cercano mide al menos 400 px

Aceptan .when(): EdgeInsets, BorderRadius, BoxConstraints, BoxDecoration, TextStyle, Color, TextTheme, GridLayout, FlexLayout, CarouselLayout y StyleProps. Un número suelto (double, int) no admite variantes: va en un StyleProps dentro de Styled (Estilos avanzados). Los anchos se cambian con ThemeData(breakpoints: Breakpoints(medium: 640)), y una variante admite las suyas: color.when(hover: hover.when(medium: other)).

La aritmética (padding * 2, padding + extra) y copyWith sobre uno de estos valores se aplican a la base y a cada variante, así que las variantes se conservan.

Nota

hover y groupHover solo se aplican con un puntero que puede flotar (mouse, trackpad). En un teléfono, repite el efecto en pressed:.

Los widgets lo reciben en sus variantes Length: EdgeInsetsGeometry.allLength (también symmetricLength y onlyLength), BorderRadius.circularLength, SizedBox(widthLength:) y Positioned(leftLength:).

Container(
  padding: EdgeInsetsGeometry.allLength(card.padding.px),
  decoration: BoxDecoration(
    borderRadius: BorderRadius.circularLength(card.radius.px),
  ),
)

SizedBox(widthLength: card.width.px, child: content)
Positioned(leftLength: drag.x.px, top: 0, child: handle)
Importante

Un EdgeInsetsGeometry no es un EdgeInsets: no tiene left ni horizontal. Los parámetros que piden EdgeInsets (TextField.contentPadding, Dialog.insetPadding) no aceptan un Length.

EdgeInsetsDirectional(start:, end:), BorderRadiusDirectional y AlignmentDirectional siguen la dirección del texto, como en Flutter.
