Códigos de error

Los errores y avisos más comunes de Thor llevan un código estable (THOR-S001) y una página aquí con la causa y cómo arreglarlo (/errores/THOR-S001). Los del navegador y del inspector de desarrollo llevan solo el código, y el overlay de thor dev los enlaza igual.

En esta página
EstadoRenderLayout (inspector de desarrollo)Páginas y servidorBuild y generación de código

Un código no se reutiliza ni cambia de significado: si un error deja de existir, su página se borra y el código queda sin uso.

Letras: S estado · R render · L layout (inspector) · P páginas y servidor · B build y generación de código.
