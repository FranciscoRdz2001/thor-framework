Features

Everything a Page Needs

The building blocks of a modern site, rendered on the server and enhanced in the browser only where it helps.

Responsive Layouts

One widget tree for phones, tablets and desktops, with breakpoints in CSS.

Accessible by Default

Native elements, real headings and labels that screen readers understand.

Typed Routes

Pages and links are checked by the compiler, not discovered at runtime.

Responsive Images

The build writes WebP variants and the page lists them, so each device downloads the right size.

Native Interactions

Dialogs, drawers, menus and accordions that work without JavaScript.

Light and Dark

A theme switch built on a checkbox and CSS variables, remembered across visits.

Common Questions

Is Thor Starter free?
Yes. It is a fictional product: this page only exists to test thor.
Do I need to know CSS?
No. Layout, spacing and colors come from widgets and the theme; the CSS is generated for you when the page renders.
Does the page work without JavaScript?
Yes. Menus, the drawer, the theme switch and this accordion are native HTML.
Where can I deploy it?
Any static host, or anywhere a small server can run.
Can I switch plans later?
Any time. Plans change at the next billing cycle.
