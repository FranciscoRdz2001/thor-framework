# thor

> thor is a Dart web framework: Flutter's widget API rendered to semantic HTML and CSS on the server (one class per element), with a small browser engine only for state that changes without a reload (`ThorState`, translated from Dart to JavaScript at build time: the lite engine, about 8–10 KB gz). Links, POST forms, `<dialog>`, `<details>` and popovers are native HTML and work without JavaScript.

Rules an agent needs first:
- Routes are a table in code, nothing generated: `lib/router.dart` with `ThorRouter([Group(layout: const AppLayout(), middleware: [session], error: const AppErrorPage(), children: [ThorRoute('/item/:id:int', const ItemPage())]), SitemapRoute(sitemap)])` (routes only); the app is one value, `final app = ThorApp.router(routerConfig: router, theme:, styles:, supportedLocales:, localeStrategy:, navigation:)`, served with `runApp(app)` or `RouteHandler(routes: app.routes, locales: app.localeRouting, renderer: WidgetRenderer.router(app))`. A page is `class ItemPage extends ThorPage<Item>` (`load`, `build`, `meta`, `redirect`, `actions`; settings in `super(cache:, transition:…)`); a layout `ThorLayout<T>`. Params: `request.param('slug')`, `request.paramInt('id')`. Links: `itemRoute.link({'id': 3})` (checked, THOR-P014). Writes: `actions` (POST → 303; `ActionResult.fail(422, data)` repaints the form).
- Browser state is a `class CartViewModel extends ThorState` (`state()` fields and methods; no `part`, nothing generated next to it: thor lists its members in `.dart_tool/thor/`, never imported). Run and test the app through thor (`thor dev`, `thor build`, `thor test`): a bare `dart run`/`dart test` that renders a state fails with THOR-S010. Widgets take its methods as tear-offs (`onPressed: cart.add`), never closures. A construct the lite engine can't translate is a build error with file:line (THOR-B012), never a silent fallback.
- Forms: a `const FormSchema` of typed fields validates on the server with the browser's rules; returning the failed form from an action is a 422.
- Environment: `lib/env.dart` with a `const EnvSchema` (typed, checked at startup; secrets never reach HTML).
- Responsive: `.when(medium: …)` on the value (`EdgeInsets`, `GridLayout`, `FlexLayout`, `StyleProps`), `LayoutScope` + `.when(container: {440: …})` for container queries. No raw CSS strings.
- See a page: `thor render /route` (HTML, CSS, errors with THOR codes, layout warnings with file:line, accessibility tree, screenshots). MCP: `thor mcp` (tools `render`, `error_code`).
